The six results

What this stores. Your voice never leaves the phone — it is measured in memory and discarded, and there is no upload of it anywhere in this page. The six results above are saved on this phone only, and Start over erases them. The one thing the server holds is the notification address from step 4, in memory, because a push cannot be sent without it; it is forgotten when the server restarts, and Start over deletes it immediately. No account, no password, no analytics.
