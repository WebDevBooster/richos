$ gh api repos/WebDevBooster/richos/actions/permissions
{"enabled":true,"allowed_actions":"all","sha_pinning_required":false}

  SHA pinning is not ENFORCED by repository policy, so the pin on the vouch
  action is a convention this tree keeps rather than a rule GitHub applies.
  Turning the policy on is the maintainer's call and is discussed in
  `.github/workflows/README.md`; nothing in the tree has to change first.
