RESTART / MULTI-THREAD / SCOPE — THE TEN RUNS THAT PROVE THE SUITE CAN FAIL
==========================================================================

app/ui/tests/restart-scope.js reports 12/12 against the tree as it stands. That number is
worth nothing on its own: a check that cannot fail is a check that examined nothing, and
this repository has produced both kinds in one week — a scanner reporting CLEAN over an
empty corpus, and a reporting layer dead for weeks because its fixtures were missing one
field.

So every check in that suite was run RED, once, by breaking the thing it guards in the
SHIPPED source and watching the suite say so. Below is each mutation, the checks it turned
red, and the words the suite printed. Every mutation was reverted immediately; the file
was restored from a copy taken before the edit, and `git status` is clean.

The mutation driver applied exactly one edit per run, refused to proceed unless the target
string matched exactly once, and restored the file whether the run passed or failed.

Two of these deserve a note.

  * MUTATION 5 (the fence's threadId clause) turns TWO checks red, and it took a second
    pass to make it turn the first one red at all. The scope check originally streamed a
    turn from another ENTITY, which the fence's separate entityId clause catches on its
    own — so deleting the threadId clause left it green. The same-entity half (`hiring`
    and `acme` are both FemcBoost) was added because of that run.

  * MUTATION 10 (`supersedesTurnId`) is the reason the crash check samples the whole
    recovery window instead of reading the end state. The reconciliation reload at turn
    end re-projects from the durable snapshot, where a superseded turn contributes
    nothing — so the end state is correct even with the renderer's merge disabled, and the
    first version of that check passed under this mutation. What the CEO would actually
    have seen is two turn sections DURING the recovery, which is now what is measured.

  a reason that has nothing to do with scope. SCOPE's real demonstrations are M5 and M6.
