MUTATION RUNS — app/ui/tests/scale.js
=====================================

A check that cannot fail proves nothing. Every one of the twelve checks in `scale.js` was
run RED at least once by breaking the thing it guards IN THE SHIPPED SOURCE — never by
editing the test — and the file was restored with `git checkout --` after each run.

Engine: WebKit Version/26.5 (Playwright 1.61.1, webkit-2311). Date: 2026-08-30.

THE FOUR THAT DID NOT GO RED THE FIRST TIME, AND WHAT THAT COST
---------------------------------------------------------------
This section is the reason the file exists. Four mutations passed, and three of them were
defects in the CHECKS, not in the mutations:

  * `overflow-y: hidden` on `#conversation` left the scroll check GREEN. `scrollTop` can be
    set on a container that does not scroll, so a timing-only check passes perfectly on a
    timeline the CEO cannot scroll at all. The check now asserts the computed `overflow-y`
    and that the history overflows the viewport by 10x before it times anything.

  * The projection budget was 60ms and the BASELINE it exists to catch was 34ms — it would
    have passed on the very code it was written against. Now 20ms.

  * Replacing the steering predicate's top-two maximum with a plain maximum left the check
    GREEN, because every turn in the mix had its prompt written before its own span opened
    and so the exclusion never had to be decided. Turn `j` was added — prompt ON its own
    start — which is the only shape in which the guard does any work.

  * `M11` was a broken mutation (guarded by an undefined flag), not a weak check; rewritten
    to raise a genuine uncaught page error.
