# Desktop engine profile and repository connections

Intermediate local verification for the app and engine 1.2.0 implementation.
This is not an installed release acceptance receipt.

The ordinary lease factory now verifies the selected engine and runtime inventory,
creates a private neutral coordination repository and loads a generated engine
plugin beside the existing app skills. Generic worker and reviewer definitions
ship in the engine. Nine native events enter one desktop wrapper, which delegates
workspace decisions and reliability checks to their canonical components.
Private state stays outside engine code. Child settings exclude ordinary host
CLAUDE.md/rules and disable auto memory for that child. Managed provider policy
remains a separate acceptance consideration.

A company folder does not automatically grant repository execution. The app has
an explicit Connected repositories surface. It accepts an existing main Git
checkout or initializes an explicitly selected empty directory. It preserves
local edits, refuses overlapping companies and does not adopt linked worktrees,
engine directories or app storage. Registry schema 2 records those connections;
version 1 loads with no execution grants and is backed up before replacement.

Desktop native permission requests now reach an app-owned decision desk. Each
answer applies to the displayed action in its exact entity/thread/session/turn
binding. Closed grants, changed bindings, declined actions and expired requests
are denied. The host-scoped onboarding and continuity tools retain their own
validated write contracts. Permission decisions remain in the existing machinery
journal. No approval creates a host-wide provider rule.

Engine setup holds the idle spine and correction writer through replacement.
Unsettled worker observations block setup. Cached provider hooks are retired
before replacement; Loro readers and writers are resolved together afterward.
Desktop worker observations read the explicit callback journal, with no terminal
team-directory fallback. A started run without an end is reported as unknown;
SubagentStop is not task completion. Full restart reconciliation remains pending.
