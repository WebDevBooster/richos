# techy mode Phase 2 — mutation runs, 2026-08-30

Every check in `app/ui/tests/techy.js` was run RED at least once by breaking the SHIPPED
source, not the test. This is the record: the mutation, the file, and which checks noticed.

A check that has never failed is a check nobody has verified. The suite reports 17/17 green
against the real renderer, the real mock and the real Rust constants; the numbers below are
what that green is worth.

## How this was produced

`/tmp/mutate.py` (transcribed at the foot of this file): for each mutation, read the file,
write the mutated copy, run `node techy.js`, restore the original in a `finally`. One
mutation live at a time, always restored, and `git diff` over `app/ui/main.js` and
`app/ui/timeline.js` is empty afterwards.

**A run of this sweep was killed by a two-minute command timeout partway through, and the
next run baked the live mutation into the source** — which is why mutation 8's second-run
result read "MUTATION DID NOT APPLY" while eleven unrelated checks went red under every
other mutation. That is what the `finally` above is for; it was added after, and the whole
sweep was re-run from a restored tree. Recorded rather than tidied away, because a mutation
harness that can leave a mutation behind is a worse defect than any it finds.

## The harness

```python
M = [ (n, relative_path, old_text, new_text), ... ]   # 17 rows, one per mutation
for n, rel, old, new in M:
    src = open(path).read()
    try:
        open(path, "w").write(src.replace(old, new, 1))
        r = subprocess.run(["node", "techy.js"], cwd=TESTS, capture_output=True, text=True)
    finally:
        open(path, "w").write(src)          # <- added after the killed run above
    record(n, r.returncode, [l for l in r.stdout.splitlines() if l.startswith("  FAIL")])
```
