# Prospects

Written 2026-09-06 from the sources named at the bottom. **Not yet confirmed by him.**

## What it is

Prospects is the outreach operation: finding the people worth approaching, learning enough about
each one to write something worth reading, and tracking what happened.

It is run as a machine rather than a habit. One list is the truth — a single roster with one row
per person, carrying that person's whole story from first sight to reply. Everything else is
either an input that gets merged in, or a view built from it.

The loop is: something arrives, it gets filed, the roster and everything built from it are
rebuilt automatically within seconds, and the result is committed. Nothing has to be re-run by
hand.

## The rule that matters most

**This folder holds real people's names, employers and profile data, and it never leaves this
machine.** There is no copy anywhere else and there must never be one. Nothing here is published,
pushed or shared, and that is not a preference — it is the condition under which the data is held
at all.

Anything written about this company follows the same rule. Names do not go into messages,
summaries or records that live elsewhere.

## House rules

- **One list, never two.** A second list of prospects is how the real one becomes wrong.
- **The rebuild is automatic and owns its own record-keeping.** Work is done by editing the
  ledgers and letting the rebuild happen, not by editing what the rebuild produces.
- **A correction is never overwritten.** Columns filled in by hand survive every rebuild.
- **The dashboard opens from the folder** — no server, no network.

## Words used here

- **Roster** — the one list. **Row** — one prospect, cradle to grave.
- **Tier** — how promising a prospect is. It is a column on the row, never a separate list.
- **Dossier** — what has been learned about a prospect, used to write to them.
- **Opener** — the first message sent.
- **Adjudication** — the decision that someone is or is not a prospect.
